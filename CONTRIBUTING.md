# Contributing

Thanks for your interest in contributing to OBS Multi User-Management-System! We welcome contributions of all sizes. Please follow these guidelines to make the process smooth.

1. Fork the repository and create a feature branch for your work.
2. Open an issue describing the problem or feature before submitting a large PR.
3. Keep changes focused and small; one logical change per pull request.
4. Write clear commit messages and include tests where applicable.
5. Run any included linters or tests before submitting.
6. Ensure you sign-off or agree to the repository license (MIT).

For security issues, please see SECURITY.md.
